# SIH26042 Audio Asset Specification & Classroom Acoustic Standards

**Version**: 1.0.0  
**Scope**: Audio assets packaged into `.slp` archives for primary tribal classrooms.

---

## 1. Classroom Acoustic Requirements

Primary school classrooms in rural tribal areas have high ambient noise levels (children murmuring, tin roofs in monsoon rain, courtyard activities). Consequently, audio assets played by the Co-Teacher must satisfy strict acoustic clarity standards:

| Parameter | Standard | Rationale |
|---|---|---|
| **Container & Codec** | **16-bit PCM WAV** (`audio/wav`) | Deterministic zero-decompression latency, universal Android playback compatibility. |
| **Sample Rate** | **16,000 Hz** (16 kHz) | Matches acoustic model sampling rate and voice frequency range (`0-8 kHz`). |
| **Channels** | **1 (Mono)** | Classroom tablet single-speaker output; halves file size. |
| **Bit Depth** | **16-bit Linear PCM** | High dynamic range without quantization noise. |
| **Duration Range** | **300 ms – 5000 ms** | Short classroom commands (`0.5s - 2.5s`). |
| **Peak Normalization** | **-1.0 dBFS** | Maximum audibility without digital clipping or distortion on cheap tablet speakers. |
| **Silence Padding** | **50 ms start / 100 ms end** | Prevents click/pop artifacts on Android `AudioTrack` initialization. |

## 2. Audio Manifest Schema (`audio_manifest.json`)

Every compiled `.slp` pack contains `audio_manifest.json` generated by `AudioValidator`:

```json
[
  {
    "audio_file": "ph_sit_down_01.wav",
    "relative_path": "audio/ph_sit_down_01.wav",
    "format": "wav",
    "codec": "pcm_s16le",
    "sample_rate": 16000,
    "channels": 1,
    "bit_depth": 16,
    "duration_ms": 500,
    "file_size_bytes": 16044,
    "sha256": "9df3064e8e5f92f327b32935b4f951a623c32fbd794cf71a0f391fa0389a9081",
    "validation_status": "SYNTHETIC_PROTOTYPE"
  }
]
```

---

## 3. Strict Verification & Honest Classification

In accordance with the project's **Trust Rule**:
- Audio files generated synthetically or recorded as test fixtures must be explicitly marked:  
  `validation_status: "SYNTHETIC_PROTOTYPE"` or `"PENDING_NATIVE_RECORDING"`.
- Under NO circumstance may a file be marked `"NATIVE_VERIFIED"` without logged metadata of the native speaker, recording session date, and pedagogical review sign-off.
